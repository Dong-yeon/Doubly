# 스토어 이미지 (Google Play · App Store)

> **스크린샷은 실제 앱 화면이어야 한다.** 양 스토어 모두 심사 기준이고, 앱과 다른 목업을 올리면
> 반려 사유다. 그래서 여기 있는 것은 **캡처를 얹을 배경판**이지 화면 그림이 아니다.
> 캡처는 폰에서 직접 찍는다.

`frontend/` 밖에 둔 이유: `frontend/assets/` 아래 파일은 EAS fingerprint 입력에 섞일 수 있고,
그러면 JS 만 바뀐 배포에도 빌드가 한 번 더 강제된다(`docs/OTA_PREFLIGHT_2026-09-14.md` 2절이
아이콘·폰트에서 실제로 겪은 일이다). 스토어 자산은 앱 번들과 무관하므로 저장소 루트에 둔다.

## 쓰는 법

1. 폰에서 화면을 찍어 한 폴더에 넣는다. **파일 이름을 문구 키로 지으면**(`04-place.png`)
   그 자리에 들어간다. 키가 아닌 이름은 남은 문구에 이름순으로 배정된다.
2. 합성한다.

```bash
python3 store/compose.py store/shots                    # 여섯 크기 전부
python3 store/compose.py store/shots --size play-phone  # 하나만
```

결과는 `store/out/<크기>/` 에 떨어진다(이 폴더는 커밋하지 않는다 — 용량이 크고 다시 만들면 된다).
어떤 캡처가 어느 문구에 붙었는지 실행할 때마다 찍어 주니 한 번 보고 넘어간다.

**이름을 키로 짓는 이유**: 다섯 장이 한꺼번에 준비되는 일이 잘 없다. 한 장만 빼고 먼저 찍어두면
이름순 방식에서는 **나머지 문구가 통째로 한 칸씩 밀려** 엉뚱한 화면에 엉뚱한 문구가 붙는다.
키로 지으면 빠진 자리만 비워두고 나중에 그 파일만 넣어 다시 돌리면 된다.

`store/shots/` 에 `02-sticker`~`05-streak` 가 이미 들어 있다. **`01-photo.png` 한 장만 찍어
넣고 위 명령을 다시 돌리면 다섯 장이 완성된다** — 나머지를 다시 찍을 필요가 없다.
결과물(`out/`)과 달리 원본 캡처를 커밋해 두는 이유가 이것이다.

### 캡처는 9:19.5 로 찍는다

자리(`slot_box`)가 **9:19.5** 다. 16:9 로 찍으면 `cover` 가 좌우를 잘라내 **사이드바·전송 버튼
같은 가장자리 UI가 썰린다**. adb 로 화면을 잠깐 그 비율로 바꿔놓고 찍는 게 제일 깔끔하다.

```bash
adb shell wm size 1080x2340 && adb shell wm density 420   # 찍기 전
adb shell wm size reset && adb shell wm density reset     # 다 찍고 반드시 되돌리기
```

`adb exec-out screencap -p > 04-place.png` 로 받는다(`adb shell` 은 CRLF 로 PNG 를 깨뜨린다).
상태바가 찍혀 있어도 괜찮고, 오히려 실제 화면이라는 근거가 된다.

### 문구·크기를 바꾸려면

`make_plates.py` 의 `CAPTIONS` · `SIZES` 를 고치고 다시 돌린다.

```bash
python3 store/make_plates.py
```

필요한 건 Pillow 하나뿐이다(`pip install pillow`). 브라우저도, 이 작업 환경도 필요 없다.

**한 장만 고쳐도 여섯 장을 전부 다시 만든다.** Pillow 버전에 따라 상단 워드마크의 자간이
미세하게 달라지는데, 여섯 장이 스토어에 나란히 걸리므로 한 장만 다른 Pillow 로 만들면
그 자리만 로고 폭이 다르다. `make_plates.py` 는 어차피 전부 다시 그린다.

### 「우리 이모지」를 뺐다가 되살린 이유 (2026-09-17 → 09-29)

원래 문구는 `우리 얼굴로 만든 / 이모티콘으로` 였다. 그 화면을 찍으려면 **실제 얼굴로 이모지를
생성**해야 하고, 생성에 쓴 얼굴이 스크린샷에 그대로 나가 스토어에 공개된다. 스크린샷에
실명·애인 얼굴을 올리지 않는다는 원칙과 정면으로 부딪혀 **스티커**로 바꿨다(처음엔 더비·블리, 2026-09-28 부터 달걀이·구운이 —
캐릭터를 바꾸면 `make_plates.py` 의 02 문구도 함께 바꾼다).
되돌리려면 공개해도 되는 얼굴을 먼저 정해야 한다.

**2026-09-29 되살림**: 공개해도 되는 얼굴 = **실존하지 않는 얼굴**. `scripts/couple-emoji-experiment/make-face.mjs`
