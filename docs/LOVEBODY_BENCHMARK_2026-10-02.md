## 1. 지금 럽바디 (9/23 구현 후)

제목 "럽바디" + 통계·캘린더 아이콘 → 운동 체크인 카드(고정, "운동 완료"/"오운완 사진", 완료 후 시간 칩) →
(스크롤) AI 버튼 둘(주간 식단 코칭·커플 주간 레터) → 스트릭 한 줄 → 오늘 영양 카드(**단백질 링** + 막대 3 + 남은 칼로리) →
물 한 줄 스테퍼 · 단식 한 줄 → 커플 식단 목표 → 오늘 식사 카드 목록 → 하단 "식단 기록하기".

기록 수단: **AI 사진**(`AI_FOOD_PHOTO` FREE 5/일·PRO 30/일), **AI 텍스트**(`AI_FOOD_TEXT`), 바코드, 음식 검색, 어제 복사, 즐겨찾기 음식 선물.
**없는 것**: 헬스 플랫폼 연동(HealthKit/Health Connect — 저장소 0건), 걸음 수, 체중 추세 예측, 음성 기록.

## 4. 개선 방향 (권장 순서)

### 소 — 업데이트

1. **오늘 요약의 주인공을 "남은 칼로리"로**(또는 링 중심값 선택). 단백질은 막대로 유지. 근거: 시장 관례 + 사용자 층이 운동 → 커플 다이어트로 이동.
2. **주간 스트립**: 제목 아래 7칸, 칸마다 나·상대 기록 점 두 개(소유자 색 + 모양 구분 — 22일 리뷰 §3-2 색맹 문제). 오늘 칸 강조. 탭하면 그날로.
3. **식사 카드에 상대 반응**: 하트·빠른 한마디("맛있겠다", "나도 먹고 싶어"). **확인 결과** `FeedItemType.MEAL` 로 반응이 이미 있다(우리 탭 피드) — 럽바디 `MealCard` 에는 노출되지 않는다. 노출만 붙이면 된다(소).
4. ~~기록 흐름 광고 금지 점검~~ — **해당 없음**: 앱에 광고 SDK 가 아직 없다(2026-10-02 grep). 광고를 붙일 때 이 원칙을 적용한다.

### 중 — 업데이트(+백엔드)

5. **채팅에서 바로 식단 기록**: 채팅에 음식 사진을 보내면 "식단으로도 남길까요?" 제안 → AI 사진 분석 재사용. 다톡이의 채팅형 기록을 **커플 채팅 안에서** — 다른 식단 앱이 못 하는 것.
6. **달걀이 반응 캐릭터**: 영양 카드 옆 작은 달걀이 — 기록 전/목표 안/초과/둘 다 기록 상태별 표정(기존 스티커 PNG 재사용). 인아웃 패턴을 우리 캐릭터로.
7. **체중 추세 + 예상 도달일**: BodyMetric 데이터로 7일 이동평균 + 목표 도달 예상일. **기본 비공개**(상대에게 안 보임), 공유는 선택.

### 대 — 네이티브 빌드

8. **Health Connect / HealthKit 연동**: 걸음·운동 세션 읽기 → 체크인 자동 제안("오늘 8,000보 걸었어요 · 운동 완료로 남길까요?"). 권한·심사 문구 필요. K1·Pretendard·앱 아이콘과 같은 빌드에 묶는다.
9. 음성 기록 — 텍스트 AI 경로에 음성 인식만 붙이면 되지만, 효과 대비 우선순위 낮음.

## 5. 하지 않을 것 · 확인 필요

**하지 않을 것**
- 타인과의 커뮤니티 배틀(인아웃) — `LIFECYCLE_DIRECTION` 의 커뮤니티 보류 원칙.
- 혈당 CGM·영양제·생리주기·수면(필라이즈) — 민감정보·범위 밖.
- 미량영양소 수십 종(Cronometer), 매크로 사이클링(MacroFactor) — 전문가용. 커플 앱의 깊이가 아니다.
- 음식 신호등 색(Noom) — 앱 색이 이미 "사람" 의미를 진다(색 의미 충돌).

**확인 필요** (1·3번은 2026-10-02 확인 완료 — §4 반영)
1. ~~식사 카드 반응~~ — 피드에 MEAL 반응 있음, 럽바디 카드엔 없음.
2. 상대에게 체중·신체 정보가 보이는지 — 지금 공개 범위.
3. ~~FREE 광고 노출 위치~~ — 광고 SDK 없음.
4. 실기기 캡처 — 9/23 정리 후 화면을 경쟁 앱 캡처와 나란히 놓고 §4-1·§4-2 를 확정.
