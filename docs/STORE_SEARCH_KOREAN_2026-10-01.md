# 스토어에서 "더블리"로 검색하면 안 나온다 (2026-10-01)

> **한 줄**: 두 스토어 모두 검색 색인의 무게는 **앱 이름**(+ iOS 부제·키워드, Play 짧은 설명)에
> 실린다. 지금 이름이 `Dubly` 뿐이라 영어로만 걸린다. 설명문의 "Dubly(더블리)"는 거의 힘을 못 쓴다.
> 콘솔에서 등록정보만 고치면 되고, 빌드는 필요 없다.

## 1. 원인

- `frontend/app.json` 의 `name` 은 `Dubly`, 콘솔의 앱 이름도 `Dubly` 로 올라가 있다(`STORE_LISTING_2026-09-17.md` 표).
- **App Store** 검색은 **앱 이름·부제·키워드 필드**만 색인한다. 설명문은 색인하지 않는다.
  그래서 설명에 "더블리"가 있어도 검색에는 걸리지 않는다.
  한국 스토어에서는 **한국어 현지화**의 이름·부제·키워드를 쓴다. 기본 언어만 영어로 두고
  한국어 현지화가 없으면 영어 메타데이터로만 검색된다.
- **Google Play** 는 설명문도 색인하지만, 무게는 **앱 이름 > 짧은 설명 > 자세한 설명** 순이다.
  설치 수가 적은 새 앱은 설명 속 단어만으로는 순위에 오르기 어렵다.

## 2. 고칠 곳 (콘솔 — 사용자가 직접)

| 스토어 | 필드 | 제안 |
| --- | --- | --- |
| App Store (한국어 현지화) | 앱 이름(30자) | `더블리 Dubly - 커플 앱` |
| | 부제(30자) | `우리 얼굴 이모티콘·커플 기록` 같은 문구. 이름과 겹치는 단어는 빼는 게 낫다 |
| | 키워드(100자, 쉼표 구분·공백 없이) | `더블리,dubly,커플,커플앱,디데이,기념일,커플채팅,연애,이모티콘` — 이름에 이미 있는 단어는 다시 넣어도 점수가 오르지 않는다 |
| Google Play (한국어 기본 등록정보) | 앱 이름(30자) | `더블리 Dubly - 커플 앱` |
| | 짧은 설명(80자) | 첫머리에 "더블리"를 한 번 넣는다 |

- App Store 의 이름·부제·키워드는 **다음 버전 심사 때** 함께 바뀐다(프로모션 텍스트만 심사 없이 바뀐다).
  한국어 현지화를 새로 추가하는 경우도 같다.
- Play 는 등록정보 검토라 보통 몇 시간에서 하루면 반영된다.
- **홈 화면 아이콘 밑 이름**(`app.json` 의 `name`)은 이 문제와 관계없다. 바꾸면 네이티브 빌드가 필요하므로 건드리지 않는다.

## 3. 알아 둘 것

- 이름을 고쳐도 반영과 재색인에 며칠 걸릴 수 있다. 상위 노출은 설치 수와 평점에도 좌우된다.
- 선행상표 "더블리(THEVELY)"(렌즈)가 있다. 같은 검색어에서 경쟁할 수는 있지만 다른 류라 공존 가능성이 높다(메모리: 상표 검색 2026-08).
