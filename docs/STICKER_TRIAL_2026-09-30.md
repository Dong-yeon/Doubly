# 무료 움직이는 이모티콘 후보 실기기 비교 (2026-09-30)

지금 쓰는 Noto Animated Emoji(Lottie 110종) 옆에 둘 후보 두 가지를 채팅 말풍선과 같은 크기로 그려 비교했다.

- **실험 코드**: 브랜치 `exp/sticker-trial`(4b2bfe45). **main 에 병합하지 않는다** — 시험 에셋이 55MB 다.
  원격에도 올리지 않았다(로컬 브랜치만).
- **여는 법**: dev build + Metro 에서 `doubly://dev/sticker-trial`, 또는 설정 맨 아래 "(개발용) 스티커 실험실".
  약관 재동의 게이트와 상관없이 열리도록 루트 스택에도 개발용으로 등록해 두었다.
- **라이선스 근거**: `scripts/sticker-trial/manifest.json`(exp 브랜치). LottieFiles 는 파일마다 원본 URL·작가·확인일을 남겼다.
- **스크린샷**: `.claude/worktrees/couple-emoji-animation-spec-30f412/scripts/sticker-trial/shots/`(gitignore, 커밋 안 함).
  워크트리를 아카이브하면 함께 사라진다.
  - `android_fluent_apng_light.png` / `android_fluent_webp_light.png` / `android_fluent_webp_dark.png`
  - `android_noto_dark.png` / `android_lottiefiles_dark*.png` / `android_mix_light.png`
  - `fluent_upscale_3x_vs_2x.png`(3x 화면 추정) / `lottiefiles_candidates.png`(후보 18종 한 장)

## 비교 조건

- 기기: Android 403WIBF001797(1200×2000, **density 240 = 1.5x**) — 132dp 가 198px 로 그려진다.
- **iOS 기기가 연결돼 있지 않아 iOS 는 전부 미확인이다.**
- 132×132, 채팅 배경 팔레트(`chatPalette`) 위에 라이트/다크를 바꿔 가며 봤다.
- 글 말풍선 10개 사이에 스티커를 섞은 목록이다. 실험실에서는 전부 무한 반복시켰다(최악 조건). 실제 채팅은 한 번만 재생한다.
- 전송은 하지 않는다 — 서버가 모르는 코드는 유니코드로 통과돼 상대에게 코드 글자가 보인다.

**끊김 측정의 한계**
- 방법: `dumpsys gfxinfo` 의 스와이프 6회 전후 janky 프레임 차이.
- 결과: 모든 탭이 43~99% 로 흔들렸고, 같은 탭을 다시 재도 68%↔96% 가 나왔다. 개발 빌드(JS dev 모드)라 절대값은 의미가 없다.
  - Fluent APNG 가 43·44·64% 로 가장 낮게 나온 회차가 많았다.
  - Lottie 탭(Noto·LottieFiles)은 63~99% 였다.
  - **"이미지 방식이 Lottie 보다 무겁지는 않다"까지만** 말할 수 있다.
- 메모리(PSS)도 탭 사이 차이가 ±100MB 안쪽이라 잡음과 구분되지 않았다.
- 결론을 내려면 release 빌드에서 다시 재야 한다.

**LottieFiles 에서 더 걸린 것**
- 캔버스 여백이 제각각이다: 커플 곰·사랑 토끼는 1000px 캔버스 안에 그림이 작아서 132 에서 절반 크기로 보인다.
- 작가가 5명이라 그림체가 한 팩으로 묶이지 않는다.

**LottieFiles 에서 뺀 후보** (manifest `lottiefiles_excluded`)
- 빨간 곰: 토이스토리 랏소와 닮았다.
- 주황 뚱냥이 3종: 가필드와 닮을 위험이 있다.
- 판다 2종: 배경이 있다.
- Lolo: LottieFiles 자체 마스코트다.
- Pudgy: NFT 브랜드다.
- 축하 주제: 캐릭터형 무료 후보를 못 찾아 비어 있다.

## 권장안

사용자가 미리 정한 기준(2026-09-30)에 비추어 판단했다.
- Fluent 가 낫다면 따로 팩을 만든다. 그림체는 섞지 않는다.
- LottieFiles 반응이 좋으면 "친구들" 팩으로 넣는다. 대표 캐릭터는 달걀이·구운이로 유지한다.
- 흐림이나 용량 문제가 크면 Noto 를 더 가져온다.

| 후보 | 판정 | 이유 |
|---|---|---|
| **Noto 추가(881종 중 110 사용)** | **채택 — 1순위** | 용량 문제가 크다: Fluent WebP 20종(7.3MB)이 지금 Noto 110종 전체(7.2MB)와 같다. 벡터라 3x 에서도 선명하고, 이미 쓰는 그림체라 섞임 문제가 없다. |
| Fluent (WebP) | **보류** | 1.5x 에서는 Noto 보다 입체감 있고 예쁘다. 막는 것은 세 가지다. ① 번들 용량(장당 6배), ② 3x 화면에서 약간 흐림, ③ iOS 미확인. 서버에서 내려받는 팩 배포가 생기면 **별도 팩으로만** 다시 검토한다(같은 팩에 Noto 와 섞지 않는다 — 섞기 탭에서 이질감이 분명했다). APNG 원본은 **제외**(장당 2.4MB, WebP 와 화질 차이 없음). |
| LottieFiles 캐릭터 | **보류(부분)** | 용량·선명도는 문제없다. 막는 것은 두 가지다. ① 10개 중 2개가 흰 배경, 2개가 여백 문제, ② 작가 5명이라 팩 그림체가 흩어진다. 넣는다면 **한 작가 묶음**이 현실적이다 — Abdul Latif 의 안녕 곰·안녕 하트·반한 하트·사랑 토끼(여백 정리 필요). 반응을 보고 싶으면 이 4종부터 "친구들" 팩으로. |
