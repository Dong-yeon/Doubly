# 스토어 등록정보 — 설명문·아이콘을 어디서 무엇으로 바꾸는가 (2026-09-17)

> **한 줄**: 설명문에서 **우리 이모지가 통째로 빠져** 있었고, **홈 위젯은 안드로이드 전용인데
> App Store 설명에 들어가 있었다**(심사 지침 2.3.1 — 부정확한 메타데이터). 두 스토어의 문구를
> 갈라 적고, 아이콘이 "스토어에서 바꾸는 것"과 "빌드해야 바뀌는 것"으로 나뉜다는 것을 남긴다.

코드로 남지 않는 결정이라 세션이 사라지면 근거를 되찾을 수 없다(CLAUDE.md 5절).

---

## 1. 고친 이유

바꾸기 전 문구는 이랬다.

```
Dubly(더블리)는 커플이 함께 쓰는 라이프스타일 앱이에요.
운동 기록 공유 / 식단 기록 & AI 분석 / 커플 채팅 & 통화 / 럽슐랭 / 여행 기록 / D-day & 홈 위젯
```

| 문제 | 근거 |
| --- | --- |
| **우리 이모지 누락** | 이 카테고리에서 다른 앱에 없는 유일한 기능인데 한 줄도 없었다. 온보딩 2번째 슬라이드, 스토어 스크린샷 2번이 전부 이것이다 (`ONBOARDING_AND_STORE_ASSETS_2026-09-14.md` 1절) |
| **홈 위젯 — iOS에 없음** | `react-native-android-widget` 기반 안드로이드 전용이다(`frontend/src/widget/DoublyWidget.tsx`, `app.json` plugins). iOS WidgetKit 구현은 없다. 아이폰에서 못 쓰는 기능을 App Store 설명에 적으면 **지침 2.3.1** 반려 대상 |
| **순서가 거꾸로** | 1·2번이 운동·식단이라 일반 헬스 앱과 구별되지 않는다. 검색 결과에는 **앞 2~3줄만** 노출된다 |
| **게임 누락** | 협동 스도쿠·오목·캐치마인드가 모두 있다(`com.fitto.game`) |
| **여행 기록은 과대 표현** | 진입점이 커플 캘린더 안 한 곳 + 홈의 조건부 카드뿐이다. 같은 이유로 온보딩에서도 뺐다(`ONBOARDING_AND_STORE_ASSETS_2026-09-14.md` 2절). 진입점이 생기면 그때 넣는다 |

## 3. Google Play 자세한 설명

2절과 같고 **D-day 항목만** 바꾼다 — 위젯은 여기서만 말할 수 있다.

```
■ D-day & 홈 화면 위젯
함께한 날을 휴대폰 홈 화면 위젯에서 바로 확인해요.
```

짧은 설명(80자 제한) — 42자.

```
우리 얼굴로 만든 이모티콘, 둘만의 맛집 등급 — 커플이 함께 쓰는 기록 앱
```

## 4. 어디서 바꾸는가

### Google Play

**Play Console → 앱 선택 → 성장(Grow) → 스토어 현황 → 기본 스토어 등록정보**
(영문 UI: Grow → Store presence → Main store listing)

한 화면에서 아래를 모두 고치고 맨 아래 **저장** 후 **검토를 위해 전송**한다.

| 항목 | 규격 | 비고 |
| --- | --- | --- |
| 앱 이름 | 30자 | |
| 짧은 설명 | 80자 | 목록에서 먼저 읽히는 줄 |
| 자세한 설명 | 4,000자 | |
| **앱 아이콘** | 512 × 512 PNG, 1MB 이하, 알파 없음 | **스토어 목록에만 쓰인다** — 아래 주의 참고 |
| 그래픽 이미지(피처 그래픽) | 1024 × 500 | `store/feature_graphic.png` |
| 휴대전화 스크린샷 | 2~8장 | `store/out/play-phone/` |

설명문만 고치는 것은 앱 심사가 아니라 **등록정보 검토**라 앱 버전과 무관하고, 보통 몇 시간~하루에 반영된다. 빌드가 필요 없다.

> **주의 — 아이콘이 두 개다.**
> Play Console에 올리는 512×512는 **스토어 페이지에 보이는 아이콘**이다.
> 사용자가 설치한 뒤 **휴대폰 홈 화면에 실제로 깔리는 런처 아이콘은 AAB 안에 들어 있다** —
> `frontend/app.json` 의 `icon` / `android.adaptiveIcon`(foreground·background·monochrome)이며
> `frontend/assets/` 의 PNG를 가리킨다. 이걸 바꾸려면 **EAS 빌드 + 새 버전 출시**가 필요하다.
> OTA 업데이트로는 절대 바뀌지 않는다(네이티브 리소스, `docs/EAS_BUILD.md` 8절).
> 둘을 같은 그림으로 유지하지 않으면 스토어와 홈 화면의 아이콘이 달라진다.

### App Store

**App Store Connect → 앱 → (버전) → App Store 탭**

- **설명 / 프로모션 텍스트 / 키워드** — 여기서 고친다
- **프로모션 텍스트(170자)** 는 심사 없이 언제든 바꿀 수 있다. 설명 본문은 **다음 버전 심사 때** 반영된다
- **앱 아이콘은 App Store Connect에서 바꿀 수 없다.** 업로드한 빌드 안의 아이콘을 그대로 쓴다
  → `frontend/app.json` 의 `icon` 을 고치고 다시 빌드·제출하는 것이 유일한 경로다
- 스크린샷: 6.9형(1320×2868) 이 필수 슬롯. 6.5형(1284×2778 / 1242×2688) 은 비우면 6.9형이 자동 축소된다.
  생성물은 `store/out/ios-6.9`, `store/out/ios-6.5` 에 있다
