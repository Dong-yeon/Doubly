# 사진 넘겨보기 2건 수정 + 상대 프로필 사진 보기 분석 (2026-10-14)

> 요청: ① 채팅에서 사진을 넘겨 보면 오늘 것만 넘어간다 ② "일상에 올린 사진을 넘겨 볼 수 없다" 문의
> ③ 상대 프로필 사진을 볼 방법이 없다 — 홈에서 누르면 상대의 오늘 기록으로 간다. ①② 는 고쳤고 ③ 은 분석·결정 대기.

## 1. 채팅 사진이 오늘 것만 넘어가던 이유와 수정

- 원인: 뷰어 목록(`ChatRoomScreen` `viewerImages`)이 **화면에 받아 둔 메시지**에서만 사진을 골랐다. 방을 열면 최근 한 페이지
  (30건)만 받으므로 사실상 오늘 사진뿐이었다. 위로 스크롤해 지난 대화를 불러오면 그만큼만 늘었다.
- 수정: 사진을 처음 열 때 사진 모아보기 API(`GET /chat/rooms/{id}/photos`, 사진첩 화면과 같은 것)를 끝까지(상한 100페이지=3,000장)
  받아 받아 둔 메시지와 id 로 합친다. 기다리지 않고 먼저 열고, 페이지가 올 때마다 앞쪽에 지난 사진이 붙는다. 방에 있는 동안 한 번만 받는다.
- `components/ImageViewer.tsx`: 열려 있는 동안 목록이 바뀌면 **보던 사진의 키로 자리를 다시 찾는다** — 앞에 사진이 붙어도 보던 사진에 머문다.
- 받아 둔 메시지 쪽이 최신이라(삭제 표시) 같은 id 면 그쪽을 쓰고, 삭제된 사진은 뺀다.

## 2. 일상 사진을 넘겨 볼 수 없던 이유와 수정

- 사진첩(우리 탭) 뷰어는 글 한 개의 사진 여러 장을 모두 넣고 있었다 — 문제는 **기록 타임라인의 카드**(`FeedCard` `PostPhotos`)였다.
  홈에서 상대를 누르면 가는 "○○님의 기록"이 이 카드다.
  - 카드 안 가로 넘김만 있었고 **눌러서 크게 볼 수가 없었다**(확대도 없음).
  - **PC 웹은 마우스로 끌어 넘길 수 없어** 첫 장 말고는 볼 길이 없었다. 몇 장인지도 작은 점뿐이었다.
  - 문의자가 폰이었다면 카드 안 넘김 자체는 동작했을 가능성이 높다 — 그래도 "더 있다"가 잘 안 보이고 크게 볼 수 없는 건 같다.
- 수정: 사진을 누르면 전체화면 뷰어(좌우 넘김·확대·저장)가 그 글의 사진들로 열린다. 오른쪽 위 `2/3` 표시.
  웹은 카드와 뷰어 양쪽에 이전·다음 버튼(마우스용). 카드 길게 누르기(고치기·삭제)는 사진 위에서도 그대로 된다.
- **실기기 미확인** — 폰에서 카드 안 넘김이 정말 막히는지(세로 목록 안 가로 스크롤)도 이번에 함께 봐야 한다.

## 3. 상대 프로필 사진 보기 — 분석

### 지금 상대 사진이 보이는 자리

| 자리 | 크기 | 누르면 |
|---|---|---|
| 홈 커플 카드(CoupleHero) | 56 | "○○님의 기록" 타임라인 |
| 채팅방 말풍선 옆 | 26 | 아무 일 없음 |
| 채팅 목록 | 52 | 채팅방 |
| 채팅방 머리(이름) | — | 아무 일 없음 |

**어디서도 상대 사진을 크게 볼 수 없다.** 데이터는 이미 있다 — `relationStore.couple.partner.profileImageUrl`(`PartnerUser` 는 id·이름·사진뿐).
사진은 프로필 자르기(AvatarCropSheet)가 **512px 정사각**으로 올린다 — 전체화면에선 조금 무르다(옛 사진은 원본 크기).

### 방법

| 안 | 내용 | 비용 |
|---|---|---|
| A. 채팅 말풍선 옆 아바타 탭 → 사진 전체화면 | 카톡과 같은 관례. 뷰어 단건 | 아주 작음 |
| B. 상대 프로필 시트 | 큰 원형 사진(누르면 전체화면) · 이름 · 함께한 날 D+N · 지금 무드·한마디 · [기록 보기] | 작음(새 공용 시트 하나) |
| C. 홈 아바타 길게 누르기 → B | 탭(오늘 기록)은 그대로 두고 보조로 | 작음 — 다만 발견이 어렵다 |
| D. "○○님의 기록" 화면 위에 큰 아바타 머리 | 홈 탭이 가는 바로 그 화면이라 자연스럽다. 누르면 전체화면 | 작음 |
| E. 프로필 사진 업로드를 1024px 로 | 전체화면에서 덜 무르다. 새로 올린 것부터 | 한 줄(OUTPUT_SIZE) |

### 권장

**B 를 공용 시트로 만들고, 들어오는 길을 셋** — 채팅 아바타 탭(A 대신 B; 시트에서 사진을 누르면 전체화면), 채팅방 머리 이름 탭, 홈 아바타 길게 누르기(C).
D 는 B 와 겹치므로 1차에선 뺀다. E 는 같이 해도 부담이 없다. 내 사진도 같은 시트로 볼 수 있게(MY 의 내 아바타) 하면 일관된다.

생일은 상대에게 보이지 않는 것이 이미 정한 원칙이라(캘린더 메모리) 시트에 넣지 않는다.

### 결정이 필요한 것

1. 권장안(B + 들어오는 길 셋)으로 갈지, A(사진만 크게)로 작게 갈지.
2. 시트에 무엇을 넣을지 — 사진·이름·D+N·무드는 기본, 그 밖에(상태 문구 등)는 데이터가 없다.
3. 홈 아바타: 길게 누르기 추가 vs 탭 동작 자체를 시트로 바꾸기(그러면 "오늘 기록"은 시트의 버튼으로).
4. 프로필 사진 1024px(E) 같이 할지.

## 4. 결정과 구현 (2026-10-14)

결정: ① 권장안(공용 프로필 시트) ② 담는 것도 권장안대로 ③ **홈 아바타 탭 자체를 프로필 시트로**, "기록 보기"는 시트 안 버튼으로 ④ 프로필 사진 1024px.

- `components/ProfileSheet.tsx` — 큰 사진 168(누르면 전체화면, 뷰어는 시트 안에 렌더) · 이름 · 함께한 지 D+N · 무드 이모지/그림 + 한마디 · [○○님의 기록 보기].
  없는 줄은 그리지 않는다. 사진이 없으면 글자 원이고 누를 수 없다.
- 홈 커플 카드: 나·상대 어느 열이든 누르면 그 사람의 프로필 시트. 내 쪽 버튼은 "내 기록 보기". 접근성 이름도 "○○님 프로필 보기"로.
- 채팅방: 말풍선 옆 상대 아바타(삭제된 메시지 자리 포함)와 머리의 상대 이름을 누르면 상대 프로필 시트. 무드는 채팅방이 이미 들고 있는 partnerMood.
- `AvatarCropSheet` 결과 기본 1024px(예전 512) — `outputSize` 속성으로 바꿀 수 있고, **우리 이모지 얼굴 맞추기는 512 유지**(AI 입력이 커지면 비용만 는다).
  이미 올린 프로필 사진은 그대로 512다 — 다시 올리면 1024.
- 검증: typecheck·웹 export·nested-buttons(새 중첩 없음)·린트(새 오류 없음). 실기기 미확인.
