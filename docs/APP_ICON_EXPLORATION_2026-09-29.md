## 1. 커플 앱 아이콘 28종 조사 (Play 검색 "커플 앱")

- **하트가 주인공**이 가장 흔하다(Love8·TheCouple·럽다·Lovify·Couply·LoveDays 등 10종). 거의 전부 분홍·빨강.
- **"둘"을 모양으로**: 두 색 하트(Everlove·Connected), 두 고리(Couple360), 두 사람이 하트(Together).

- 초록 계열은 기억나무 하나뿐. 비트윈은 1위권인데 하트도 분홍도 아니다 — 모양·이름이 "커플"을 말하면 색은 자유롭다.

## 3. 교훈

- **PIL 로 짠 기하 도형 시안은 아이콘 판단에 부적합하다.** 평평한 기하 도형 + 단색 판은 콘셉트와 무관하게
  표지판처럼 보인다. 콘셉트 탐색은 이미지 생성(나노바나나)이나 디자이너에게 맡기고, 우리는 **거르는 쪽**
  (24px 축소 · 어댑티브 원형 마스크 · 커플 앱/흔한 앱 사이 배치)을 맡는다.
- 비교 도구는 재사용 가능: `.icon-candidates/2026-09-29/dsheet.py <ref폴더> <이미지 이름...>`
  — 크기별(64/40/24) + 원형 마스크 + 밝은/어두운 홈에서 커플 앱 아이콘 사이 배치를 한 장으로 뽑는다.
  참조 아이콘 28종은 같은 폴더 `ref/`.

사용자가 짚은 핵심 메시지는 **"라이프를 함께 한다"**다. 이걸 사물 하나(집·컵·왕관)로 옮기면 뜻이 좁아지거나
다른 범주로 읽힌다 — 메시지는 맞고 번역이 어렵다. 이 브리프로 이미지 생성 탐색을 맡긴다.

## 5. 이미지 생성 라운드 — 숟가락이 처음으로 통과 (같은 날)

| 시안 | 판정 |
| --- | --- |
| 신발 두 켤레 · 우산 속 두 사람 · 발자국 | 디테일이 24px 에서 뭉갠다 / 현관은 동거 전제 / 발자국은 얼룩·등산 앱 |
| 맞닿은 두 머그 | 형태는 버티지만 **앱과 무관**(사용자: "우리 어플이랑 머그컵이랑 무슨 상관이야?") |
| 젓가락 한 쌍 | "두 짝이 한 벌"은 좋으나 가는 선이라 24px 에서 사라진다 → 사용자 제안으로 숟가락 |
| 숟가락: 포갬(spooning) · 엇갈림 · 접시 링 | 가늘어 막대로 읽힘 / 포크·나이프 X 는 식당 표시 / 식당 간판 |
| **숟가락 끝을 맞댄 "짠" + 위에 하트** | **통과.** 앱 내용(함께 먹는 일상 — 식단·럽슐랭·"밥 먹었어?")과 이어지고, 커플 앱 28종 사이에서 겹치는 게 없으며, 24px 에서 하트와 두 형태가 남는다 |

통과안의 남은 결함과 처리:
- 손잡이가 모서리까지 벌어져 **어댑티브 안전원(중앙 66%) 밖으로 마크의 17.6%** 가 나간다 → 손잡이를 짧고 굵고 덜 벌어지게 다시 뽑는 중. 안 되면 안드로이드 전경만 80% 로 줄인다.
- 전체 윤곽이 "A"/人 로 읽히고 위가 무겁다 — 위와 같은 수정으로 함께 푼다.
- Gemini 워터마크(✦)와 배경 얼룩 → 4색 양자화로 평평하게(`.icon-candidates/2026-09-29/spoon/`, `mugclean.py` 방식).
- 흰 바탕보다 크림 `#FBF6EA` 가 밝은 홈에서 덜 뜬다.

확정되면: 아이콘 세트 + 스토어 512 + 피처 그래픽(아이콘과 같은 인상으로 다시) + 스크린샷 배경판 브랜드 줄 → 한 빌드에 싣는다.
사용자 방침: **아이콘·그래픽은 스토어의 얼굴이라 서두르지 않는다**(2026-09-29).

## 6. 확정과 적용 (같은 날)

- 나노바나나에 "손잡이만 짧게"를 요청했더니 원본과 99.7% 같은 그림이 돌아왔다(참조 이미지를 주면 거의 그대로 둔다).
  손잡이를 이미지로 잘라 붙여 방향(62% 길이 · 8°)을 확인한 뒤, **벡터로 다시 그렸다**: `store/icon/make_icon.py`.
- 핵심 관찰: 볼이 가운데로 기운 방향과 손잡이가 바깥으로 벌어진 방향이 **한 직선 위**에 있다 → 숟가락 = 곧은 축 +
  축을 따라 변하는 폭 함수(볼 달걀형 + 목 + 끝으로 넓어지는 손잡이 + 둥근 끝, 부드러운 합). 부품을 붙이는 방식은
  목에서 턱·꺾임이 계속 생겼다.
- 초록은 앱 primary `#2A7731`, 코랄 `#EF7757`, 바탕 크림 `#FAF5E8`.
- 안드로이드 전경은 **공식 안전 영역(108dp 중 가운데 66dp 원)** 에 맞춰 0.74. 가장 먼 점이 중심에서 422(1024 기준).
  처음엔 보이는 72dp 원을 기준으로 0.81 을 잡았는데 가이드보다 느슨했다.
- 단색(테마) 아이콘은 두 숟가락이 한 색이 되며 볼 사이 틈이 붙어 보여, 단색만 좌우로 14 씩 벌린다.
- 스플래시는 흰 바탕 위 마크만(투명 PNG), 어댑티브 배경색은 크림으로.
- 정리: `BigaeMark.tsx`(사용처 0) · `bigae-mark.svg` · `store/make_play_icon.py` · `store/mascot.png` 삭제.

**아직 남은 것**: 피처 그래픽과 스크린샷 머리 줄을 새 아이콘에 맞추기(지금 피처 그래픽은 달걀이·구운이 임시본),
실기기 홈 화면 확인(빌드 후), 인앱 로고(`DoublyMark`, 겹친 두 하트)와의 관계 정리.
