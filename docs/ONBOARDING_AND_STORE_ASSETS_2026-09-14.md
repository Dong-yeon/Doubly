# 온보딩 갱신 + 스토어 이미지 — 왜 지금 스크린샷을 찍지 않는가 (2026-09-14)

> **한 줄**: 온보딩 문구는 이번에 갱신했다. **스토어 스크린샷은 탭바 재구성이 들어간 뒤에 찍는다** —
> 하단 탭바는 모든 스크린샷에 박히므로, 지금 찍으면 탭 이름이 바뀌는 순간 전부 재촬영이다.

이 문서는 **판단 근거와 남은 체크리스트**를 남긴다(CLAUDE.md 5절). 코드로 남지 않는 결정이라
세션이 사라지면 "왜 그때 스토어 이미지를 안 갈았지"를 되찾을 방법이 없다.

---

## 1. 온보딩이 낡은 정도

`OnboardingScreen.tsx` 의 내용이 마지막으로 바뀐 것은 **2026-08-11**(`ef3526f`)이다. 그때의 3장은
기록 · 응원 · 계획이었고, 그 뒤 한 달간 붙은 것 중 온보딩에 등장하는 것은 **하나도 없었다**.

| 8/11 이후 추가 | 온보딩 반영 (갱신 전) |
| --- | --- |
| 우리 이모지 — 애인 얼굴 AI 감정 이모지 (V80, 감정 17종, 무드 연동) | 없음 |
| 움직이는 이모티콘 30종 + 자체 캐릭터 스티커 세트 | 없음 |
| 협동 스도쿠 · 오목 + 미니게임 허브 (V86/V87) | 없음 |
| 원탭 운동 완료 · 인증샷 기록 (느슨한 체크인 전환) | "운동을 기록한다" 수준 |
| 사진 한 장으로 한 끼 + 백그라운드 AI 칼로리 분석 | "식단을 기록한다" 수준 |
| 앱 아이콘 전면 교체(까꿍) | 해당 없음(아이콘은 별도) |

특히 **우리 이모지**는 이 카테고리에서 다른 앱에 없는 유일한 것인데 첫인상에서 통째로 빠져 있었다.

## 2. 갱신 내용 — 아이콘+문구 4장 유지

실제 화면 캡처를 슬라이드에 넣지 않았다. 이유는 3절과 같다 — **곧 낡는다.**
아이콘+문구는 화면 구조가 바뀌어도 살아남고, 문구만 고쳐 EAS Update 로 심사 없이 내보낼 수 있다.
같은 이유로 문구에 **탭 이름을 쓰지 않았다**(브랜드 조어 "럽슐랭"만 쓴다) — 탭 이름은 바뀔 예정이다.

| # | 액센트 | 제목 | 담은 것 |
| --- | --- | --- | --- |
| 1 | 나(Gold) | 사진 한 장이면 끝 | 사진 기록 + AI 자동 분석(운동·식단 공통) |
| 2 | 상대(Green) | 우리 얼굴로 만든 이모티콘 | 우리 이모지 → 채팅 전송 + 무드 연동 |
| 3 | 함께(Olive) | 같이 놀고, 서로 응원해요 | 협동 게임 + 피드 반응 + 스트릭 |
| 4 | primary | 우리만의 맛집 가이드 | 럽슐랭 등급 + 가고 싶은 곳/지도 |

**여행은 일부러 뺐다.** `TripList` 진입점이 커플 캘린더 안 한 곳 + 홈의 조건부 D-day 카드뿐이라
(SESSION_DIGEST 미완 6번 "여행 탭 진입 버튼" 미해결), 온보딩에서 한 장을 쓰면 과대 표현이 된다.

같이 고친 것 두 가지 — 둘 다 이 화면에 원래 있던 결함이다.

- **세로 중앙 정렬.** VirtualizedList 가 항목을 감싸는 셀 View 는 내용 높이에 머물고 flex 로
  늘어나지 않는다(실측 리스트 666 / 셀 274). `justifyContent:'center'` 가 그 짧은 높이 안에서만
  돌아 내용이 위로 몰리고 아래에 화면 절반이 비어 있었다. 리스트 높이를 `onLayout` 으로 재서
  슬라이드에 직접 준다.
- **다크모드 즉시 전환.** 슬라이드 액센트를 모듈 최상위에서 `colors.coral` 로 굳혀 두어,
  테마를 즉시 전환해도(`3fa4742`) 앱 시작 시점의 색이 남았다. 팔레트 **키**로 들고 있다가
  렌더 시점에 푼다. 덤으로 `나=Coral/상대=Indigo/함께=Violet` 주석도 현행 팔레트(Gold/Green/Olive)로
  맞췄다 — 팔레트는 이미 교체됐고 키 이름만 호환용으로 남아 있었다.

## 3. 스토어 스크린샷을 미루는 이유

확정됐지만 **아직 구현 전**인 변경 두 개가 하필 정확히 스크린샷에 찍히는 것들이다.

| 미구현 확정 사항 | 스크린샷에 미치는 영향 |
| --- | --- |
| 탭바 재구성 → 홈·럽바디·채팅·우리·럽슐랭 (`ALBUM_TAB_IA_2026-09-14.md`) | 하단 탭바는 **모든 장**에 박힌다. 탭 이름이 바뀌면 전량 재촬영 |
| 럽슐랭 동선 정리(한 목록·한 별점·한 층 덜) (`LOVELICHELIN_UX_REANALYSIS_2026-09-14.md`) | 럽슐랭 화면 구조 자체가 달라진다 |

여기에 플랫폼 비대칭이 붙는다. **Google Play 는 스토어 등록정보만 따로 수정**할 수 있지만,
**App Store 는 스크린샷 교체가 새 버전 제출에 묶인다.** iOS 쪽 헛수고 비용이 더 크다.
