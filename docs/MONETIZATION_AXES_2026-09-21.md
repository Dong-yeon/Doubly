## 1. 경계 규칙 — 원가가 가른다

축이 넷이면 같은 기능을 두 축이 탐내게 된다. 기준은 하나다.

> **변동원가가 매달 나가는 것은 구독으로만 판다. 1회 결제(영구권·상점)에는 원가 0 인
> 것만 넣는다.**

**영구권은 1회 매출인데 원가는 매달 나간다.** 원가 있는 기능을 영구권에 넣으면 사용자가
쓰면 쓸수록 적자인 상품이 된다. 비트윈 모델을 그대로 못 가져오는 지점이 정확히 여기다 —
비트윈은 스티커·테마 판매 + 광고 제거가 주 수익이고 **변동원가가 있는 구독 상품이 없다.**

그리고 원가 0 이라고 전부 1회 결제로 보내면 안 된다. 두 번째 규칙이 필요하다.

> **원가가 0 이어도 PRO 의 대표 기능은 구독에 남긴다.**

`PRO_UPSELL_AND_ADS_2026-09-17.md` §6 이 플랜 화면에서 앞세우라고 꼽은 넷 —
**영상통화 · 우리 이모지 · 추억 리마인드 · 전체 기간 통계** — 이 그 목록이다.
`MEMORIES`·`FULL_STATS`·`ANNIVERSARY_RECAP` 은 원가가 0 이지만 여기 속한다.
**"리소스를 적게 먹는다"와 "가치가 낮다"는 다른 축이다.**

세 번째는 광고에만 걸리는 규칙이다.

> **광고로 푸는 것은 PRO 의 대체재가 아니라 FREE 한도의 완충재다.**

`Quota.blocked()` 전부를 리워드 광고로 풀면 PRO 를 결제할 이유가 사라진다
(9/17 §4). 광고로 풀 수 있는 것은 **한계비용이 0 에 가까운 한도형**뿐이다.

## 3. 충돌 — "기본 제공 외에는 구매" vs 오늘의 무료화

같은 날 두 결정이 반대 방향으로 났다.

| | 내용 |
| --- | --- |
| **지시(이 문서)** | "기본 제공 이모티콘 외에는 스티커 상점에서 구매해서 쓰도록" |
| **오늘 구현** | 움직이는 이모티콘 **110종 8팩 전부 무료**. 예전엔 30종 중 24종이 `premium` 이었다 |

그리고 그 무료화는 **테스트로 못 박혀 있다.**

```
AnimatedStickerTest.everyStickerIsInAFreePack
PremiumContentGateTest.움직이는_이모티콘은_전부_무료다
StickerPackSyncTest.누가_무엇을_쓸_수_있는지는_그대로다   ← "무료로 준 게 다시 잠기는 것"을 막는다
```

의도적으로 세운 방어선이라, 유료 범위를 넓히려면 **이 셋을 먼저 지워야 한다.**

### 판정 — 오늘 결정을 유지한다

근거는 셋이다.

1. **Noto Animated Emoji 는 어디서나 공짜로 구할 수 있다.** CC BY 4.0 이라 파는 것
   자체는 합법이지만, 무료로 구할 수 있는 그림에 값을 붙이면 상품성이 없다.
2. **이미 무료로 연 것을 다시 잠그는 것은 기능 회수다.** 반발이 가장 큰 종류이고,
   `PLAN_FREE_TRIAL=false` 전환(모두가 한꺼번에 벽에 부딪히는 시점)과 겹치면 더 나쁘다.
3. **팔 것이 유니코드에 없는 것으로 모인다.** 9/21 문서의 논리를 끝까지 적용한 결과이고,
   2026-09-14 에 `StickerPack` enum 을 지운 근거("폰 키보드에 이미 있는 글자를 파는 모양")와
   같은 잣대다.

**그래서 "기본 제공"의 정의를 이렇게 고정한다.**

> **기본 제공 = 유니코드에 이미 있는 것**(움직이는 이모티콘 110종 · 기본 무드 · 기본 터치).
> **파는 것 = 유니코드에 없는 것**(자체 캐릭터 스티커 · 우리 이모지 · 확장 무드 · 프리미엄 터치).

지시의 의도("기본 제공 외에는 판다")는 이 정의로 **그대로 성립한다.** 다른 것은 "기본
제공"의 범위뿐이다.

### 4-1. AI 맛보기를 막으면 안 되는 이유

지시는 "AI 트래픽을 소모하는 것은 PRO"였다. 문자 그대로면 맛보기 5개도 올라가야 하는데,
**두 근거가 반대 방향이다.**

- **원가**: `AI_COST_ANALYSIS_2026-09-14.md` §0 — "**텍스트 AI 는 청구서에 잡히지 않는다.
  청구액은 사실상 우리 이모지 하나다.**" 텍스트 키는 결제가 안 붙은 무료 프로젝트다.
  즉 맛보기를 막아도 **아끼는 돈이 0 이다.**
- **유입**: `AI_FOOD_PHOTO` 주석 — 사진을 저장하면 `MealPhotoAutoAnalysisService` 가
  백그라운드로 돈다. 끼니는 하루 3번인데 여기를 막으면 무료 사용자는 **"사진만 올리면
  기록된다"는 이 앱의 이유를 하루도 온전히 못 겪는다.**

**그래서 "AI = PRO"는 이미 달성돼 있다.** 돈이 나가는 AI(`AI_COUPLE_EMOJI`)는 FREE 차단이고,
나머지는 체감가치 배분이 이미 끝났다. 이 축은 **바꿀 것이 없다.**

## 5. 영구권 — 바퀴를 다시 만들지 않는다

`user_sticker_purchases`(V96)가 **영구 소유 패턴을 이미 완성해 놨다.** 영구권은 같은
모양으로 얹는다.

| 논점 | V96 이 이미 정한 답 |
| --- | --- |
| 개인 소유냐 커플 소유냐 | **소유는 개인, 사용은 커플.** 구매 행은 산 사람에게 붙고 판정은 상대까지 퍼진다 — "구독으로 열면 둘 다 쓰는데 낱개로 사면 나만 쓴다"는 설명할 수 없는 차이를 막는다 |
| 복원·재설치 | `(user_id, pack_id)` unique 인덱스로 멱등 |
| 탈퇴 | `UserDataPurger` 가 **거둔다**(FK 가 없어 빠뜨리면 조용히 남는다) |
| 이별 | `RelationRecordPurger` 는 **일부러 안 거둔다** — "관계가 끝났다고 회수하면 환불 없는 몰수" |
| 스토어 상품 id | 컬럼이 아니라 규칙 — `sticker_pack_` + id 소문자 |

### 5-1. `Plan` enum 에 세 번째 값을 넣지 않는다

`Plan.java` 주석이 "중간 등급(예: PLUS)이 생겨도 호출부가 안 깨진다"며 `isAtLeast`/`max`
를 쓰라고 해뒀지만, **영구권은 등급이 아니라 entitlement(소유권)다.**

`Plan` 에 끼워 넣으면 **PRO 구독자가 영구권을 샀을 때 등급이 내려가는 모순**이 난다.
`ordinal()` 이 곧 등급인 구조라 순서를 어디에 넣어도 성립하지 않는다.

맞는 모양은 `StickerService.requireUsable` 과 같다 — **"플랜으로는 막혔지만 소유권으로
열림" 분기**를 `PlanGuard` 앞에 두고, 마지막 갈래만 `PlanGuard` 에 위임한다. 402 문구,
`PLAN_UPGRADE_REQUIRED` vs `USAGE_LIMIT_EXCEEDED` 구분, `FEATURE_USED`/`FEATURE_BLOCKED`
계측이 전부 거기 있어서, 직접 던지면 그 경로에서만 지표가 사라진다.

### 5-2. 검증 경로가 구독과 다르다

영구권은 Play 의 **일회성 상품(`inapp`)** 이라 `pro_monthly`(`subs`)와 API 가 다르다.
`StickerPurchaseService` 가 이미 그 경로를 뚫어놨으므로(`purchases.products.get` /
`/inApps/v1/transactions/{id}`) 같은 서비스를 재사용한다.

> **환불 웹훅이 아직 없다.** 9/21 문서 §13-5 — 스토어 콘솔에서 환불해도 팩이 계속 열린다.
> 영구권까지 붙으면 이 구멍이 커진다. 상점만 있을 때보다 우선순위를 올려야 한다.

## 6. 광고 — 선행 조건이 셋이다

영구권의 본체가 "광고 제거"인 이상 **광고가 먼저다. 없는 것을 제거하는 상품은 못 판다.**

| 선행 조건 | 상태 |
| --- | --- |
| 볼 사람이 있을 것 | `PLAN_FREE_TRIAL=true` → **FREE 0명** |
| SDK 가 붙어 있을 것 | 코드 **0줄**. AdMob 은 `app.json` plugins 변경 → **EAS 빌드**(OTA 불가, `CLAUDE.md` §6) |
| 리워드면 SSV 서버 | 미착수 |

붙인다면 대상은 **한계비용이 0 에 가까운 한도형부터** — `VOICE_MESSAGE`(일 5),
`AI_FOOD_TEXT`(일 2). `AI_COUPLE_EMOJI` 는 **광고 수익 < 장당 원가($0.045)** 라 영구 제외다
(9/17 §4).
