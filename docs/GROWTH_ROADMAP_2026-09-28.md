## 5. 트랙 D — 이모티콘 · 스티커

### 5-1. "AI 이미지 생성 + 무료 에셋"에 대한 판단

**무료 에셋 — 무료 트랙 확장용으로만 쓴다.**

| 소스 | 라이선스 | 쓰임 |
| --- | --- | --- |
| Noto Animated Emoji | CC BY 4.0 (이미 고지 중) | 지금 110종 / 공식 목록(`data/api.json`) 881종(2026-09-28 확인). 목록에 있어도 Lottie 404 인 항목이 있어 실제 요청으로 걸러야 한다. 추가 비용 0, 번들 크기(9/21 에 7.7MB)만 주의 — 초과분은 서버 카탈로그(§STICKER_CATALOG_PLAN §4) 이행 시점과 묶는다 |
| Twemoji | CC BY 4.0 | 정적. Noto 와 그림체가 달라 섞지 않는 편이 낫다 |
| OpenMoji | **CC BY-SA 4.0** | 동일조건변경허락 — 유료 팩에 섞으면 안 된다. 쓰지 않는 것을 권장 |
| Microsoft Fluent Emoji | MIT(정적) | 애니메이션판의 라이선스는 **확인하지 못했다** — 도입 전 저장소 LICENSE 직접 확인 필요 |
| 일반 스톡(Freepik 등) | — | 9/17 결정대로 **금지**(재배포·앱 내 스티커 사용 제한) |

무료 에셋은 전부 "유니코드에도 있는 것"이라 **9/21 원칙(유니코드에 없는 것만 판다)에 따라 팔 수 없다.**
따라서 수익·브랜드 문제는 무료 에셋으로 풀리지 않는다.

**AI 생성 — 가능하지만 "초안 도구"로만 쓴다.**

- **저작권**: 한국저작권위원회 안내서 기준, AI 가 만든 결과물 자체는 저작물로 등록되지 않고
  **사람이 선택·배열·수정한 창작적 기여 부분만** 보호된다. 순수 생성물로 팩을 만들면 누가 베껴도
  막기 어렵다 → **사람의 보정 과정을 거치고, 그 과정(원본·수정본)을 보관**한다.
- **일관성**: 달걀이 캐릭터 PNG 를 레퍼런스로 넣는 image-to-image 로 포즈만 늘리고, 선 굵기·색은
  사람이 맞춘다. 이미 있는 Gemini 파이프라인(우리 이모지)을 스크립트로 재사용할 수 있다.
- **약관**: 사용하는 이미지 모델의 상업적 이용 조건을 생성 시점에 확인·기록한다.
- **해상도**: 말풍선 132pt × 3배 = **396px 이상**. 시트로 받으면 칸당 해상도가 부족하니 장당 생성.
- **권장 흐름**: AI 초안 30~40장 → 동연님(또는 사람) 선별·보정 16~24장 → `stickerImages.ts`
  `STICKER_CHARACTERS` + `stickerPacks.ts` `CHARACTER_PACKS` + 시드 마이그레이션. 시트 분리 스크립트는
  이미 있다(STICKER_PACK_MONETIZATION §13).

1. 퍼널 쿼리(9/25) 결과를 한 번 돌려 볼 것인가 — A3 우선순위가 여기서 갈린다.
2. 달걀이 팩 작업자: 동연님 보정 가능 여부. 불가하면 AI 초안을 쓰되 **판매는 보류하고 무료로 먼저** 낸다.
3. 본문 Pretendard 적용(C2) — 번들 +수백 KB 와 빌드를 감수할지.
4. 기념일 공유 카드에 워터마크를 넣을지(바이럴 vs 사용자 반감).
