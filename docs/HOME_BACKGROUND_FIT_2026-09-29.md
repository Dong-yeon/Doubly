# 홈 배경 사진이 확대돼 윗부분만 보이던 것 (2026-09-29)

## 증상
배경 사진을 설정하면 "이상하다" — 사진이 크게 확대된 채 **윗부분만** 보이고, 사진의 주인공(보통 가운데)이 사라진다.

## 원인
`HomeScreen` 의 배경 `<Image>` 가 `StyleSheet.absoluteFill` + `cover` 였다. 즉 사진을 **화면 전체 비율(세로로 긴)로
확대·크롭**한 뒤, 그 아래 절반 이상을 9/28 부터 불투명해진 하단 패널(히어로·슬롯·바로가기)이 덮는다.
사진 전체 스크림 시절(패널이 반투명)에는 화면 전체에 까는 게 맞았지만, 패널이 제 배경을 깔게 되면서 어긋났다.

## 고친 것
사진을 **보이는 자리(화면 맨 위 ~ 패널 윗선)** 에만 맞춰 그린다. 높이는 `body`·`panel` 의 `onLayout` 으로 잰다
(`photoHeight = bodyTop + panelTop`, SafeAreaView 의 위 여백이 bodyTop 에 들어 있다). 경계는 기존 panelFade(72px)가 덮는다.
재기 전 첫 프레임과 미연결 화면(글자가 화면 전체에 있고 전체 스크림을 쓴다)은 예전처럼 화면 전체로 그린다.

## 검증
웹 export + 가짜 API 로 위·가운데·아래에 표식이 있는 4:3 테스트 사진을 깔아 비교했다.
- 전: 가운데 원이 패널 경계에 걸려 반쯤 가려지고, 아래 표식은 안 보인다.
- 후: 위(상단 바 뒤)·가운데·아래 표식이 모두 사진 자리 안에 들어온다.

**미검증**: 실기기(iOS·안드로이드), 세로로 긴 사진.
