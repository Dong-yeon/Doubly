| 화면 | 섹션 수 | 탭 가능 요소 | 전체 추정 높이 | 첫 화면 대비 |

**정리 효과가 클 것 같은 상위 5개** (높이·탭 수 기준, 사용 데이터는 대부분 없음):

1. **기록 화면 저장 버튼이 2,059px 아래** — 하단 고정 또는 순서 재배치만으로 "어디서 끝나는지 모르는" 문제가 사라진다(§2-c).
2. **음식 카드 장당 373px·11탭** — 한 줄 행으로 접으면 (c)에서 약 1,000px·30탭이 준다(§1-2 [p]).
3. **기록 화면 사진 위의 선택 입력 400px**(날짜·끼니·같이 먹기·장소·바코드) — 한 줄 요약 + 사진 맨 위로 올리면 주 경로(사진 → 분석 → 저장)가 첫 화면에 들어온다.
4. **럽바디 메인 하단의 저빈도·중복 블록** — 물·단식(154)·이번 주(177)·AI 버튼(52)을 접으면 "○○님 오늘"이 첫 화면 쪽으로 올라온다. 셋 다 실측 없음, 물·단식·AI 는 유일한 진입점이라 접기만 가능.
5. **럽바디 고정 운동 체크인 카드** — 고정 영역 54~150px 가 스크롤해도 남는다. 스크롤 안으로 넣으면 (b)에서 첫 화면에 오늘 카드가 한 장 더 들어온다.
